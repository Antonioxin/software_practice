# Web 开发技术现状报告

[阅读报告 PDF](Web开发技术现状报告-前端技术与内容管理.pdf)

本报告以成员 E 的前端学习过程为主线：先建立 HTML、CSS、JavaScript、框架与工程工具的分类，再说明 WEMOVE 项目实际使用的技术，随后从商品卡片、文章阅读和后台图文编辑延伸调研三维展示、内容加载与编辑技术的现状和优缺点。正文采用第一人称，区分项目实践、资料调研和后续设想。资料查阅日期为 2026-09-08。

## 版式与文件

沿用[项目需求文档](../../项目需求文档/main.tex)的 A4、12pt 正文、宋体中西文、黑体标题、页边距、校名封面、信息表、目录和页眉页脚。保留姓名、学号和封面日期。内容组织为摘要、七章正文和顺序编码参考文献；表格采用模板的 11pt 宋体、浅灰分隔线与列内边距。

- [main.tex](main.tex)：封面、版式和章节入口。
- `chapters/`：可编辑正文及参考文献。
- `figures/`：校名、项目截图、TikZ 原理图及图片资源统计。
- [网络图片来源](figures/online/图像来源.md)：网络图片的原始地址、作者、许可及处理方式。
- [Makefile](Makefile)：编译入口。
- [资料与核查说明](资料与核查说明.md)：项目证据与文档核查结果。
- [核对报告脚本](scripts/核对报告.py)：字数、引用、资源和编译警告检查。
- [资源图表脚本](scripts/生成资源图表.py)：可选的工程图片重新统计工具，生成统计 JSON 及辅助图表；该图表未插入当前正文。

本目录自带编译所需图片，可独立复制并编译。只有重新统计工程图片时才需要原仓库。`.build/`、`验证/` 和临时 `main.pdf` 已忽略；正式 PDF 与源码一起保存。改写前版本在本地 `.build/改写前版本/` 中备份。

## 编译与核对

需要 XeLaTeX、latexmk 和 make，建议使用完整 TeX Live 或 MacTeX。本次使用 TeX Live 2024。正文沿用模板的 macOS 宋体与黑体；其他平台使用 Fandol 字体。字体变化可能影响分页，换环境后需重新检查。

从仓库根目录运行：

```sh
make -C "文档撰写/Web 开发技术现状/Web开发技术现状报告 徐熠潘"
python3 "文档撰写/Web 开发技术现状/Web开发技术现状报告 徐熠潘/scripts/核对报告.py"
```

输出为本目录的 `Web开发技术现状报告-前端技术与内容管理.pdf`。没有 make 的环境可以进入报告目录执行：

```sh
latexmk -xelatex -interaction=nonstopmode -halt-on-error -file-line-error -outdir=.build main.tex
```

该命令生成 `.build/main.pdf`，需要手动复制为正式文件名。

如需重新统计工程图片：

```sh
python3 "文档撰写/Web 开发技术现状/Web开发技术现状报告 徐熠潘/scripts/生成资源图表.py"
```

资源图表脚本仅需 Python 标准库与包含 PGFPlots、standalone 的 XeLaTeX。重新统计后须同步核对正文的日期、文件数和 MiB 数值。这是文件统计，不是网络性能测量。
