## 使用建议

1. 优先保留成员能够明确回忆的主题。
2. 基于代码或需求整理的内容，在成员确认后同步修订。
3. 对话尽量从具体开发问题开始，避免把表达改写成抽象的软件工程术语。
4. 转成 LaTeX 时，再统一消息框、姓名显示和讨论结论。
