# WEMOVE 网站需求文档编译说明

## 文件说明

- [main.tex](main.tex)：LaTeX 主文件，包含字体、封面、页眉页脚和章节入口。
- `chapters/`：文档说明、六章正文与文末参考文献，按章节独立编辑。
- `figures/`：模板提供的校名图片，以及零售和经销合作流程的 TikZ 矢量图源码。
- [Makefile](Makefile)：编译入口；中间文件写入 `.build/`，最终 PDF 写入本目录。

仓库仅保存源码、必要图片、编译配置和本说明。编译生成的 `WEMOVE网站需求规格说明书.pdf`、源码压缩包、`.build/` 缓存及 `验证/` 中的排版检查产物不纳入版本控制；克隆仓库后按下述命令生成 PDF。本目录的源码可独立复制并编译。

## 内容与版本

正文依据 [WEMOVE网站重构需求文档.md](../../project-implementation/project-requirements/WEMOVE网站重构需求文档.md) 的 V1.1 版本编排，需求基线日期为 2026-09-05，排版日期为 2026-09-08。

本排版版本按 2026-09-08 的修订要求删除附录 B、附录 C 及相关引用，并将参考资料改为文末顺序编码参考文献；保留核心功能需求、业务规则、数据约束、验收条件和 41 个验证场景。来源文档中的“评审通过”和验证矩阵中的“未执行”状态保持原意。本次编译与排版检查不代表应用实现或验收用例已经通过。需求发生变更时，应同时更新 Markdown 基线与相应 LaTeX 章节，并重新核对编号和验证关联；两种格式不会自动同步。

版式基于 [latex-template](../latex-template/main.tex)，沿用 A4、12pt 正文、封面信息表、目录及页眉页脚。中西文正文统一使用宋体，强调使用加粗宋体，黑体仅用于标题；分级列表采用一级阿拉伯数字、二级小写罗马数字。表格使用 11pt 宋体、8pt 列内边距、额外行高及浅灰行分隔线。封面采用项目与文档元数据。两张 Mermaid 流程图转为 TikZ，数学表达式使用 LaTeX 原生公式，长表格使用重复表头的跨页表格。

正文表格独立编号；前置文档属性和修订记录不编入正文表号。三个 UC 编号另外出现在相应用例表的标题中，因此 PDF 中每个 UC 编号比 Markdown 多出现一次。

## 编译

需要安装支持 XeLaTeX 的 TeX Live 或 MacTeX，以及 `latexmk` 和 `make`。本次使用 TeX Live 2024 编译。所用宏包包括 `ctex`、`fontspec`、`geometry`、`longtable`、`booktabs`、`tikz`、`hyperref`、`bookmark`、`titlesec` 和 `needspace`。

从仓库根目录执行：

```sh
make -C "文档撰写/项目需求文档"
```

也可以进入本目录执行：

```sh
make
```

编译会自动运行所需轮次以生成目录和交叉引用，并将 PDF 复制为 `WEMOVE网站需求规格说明书.pdf`。Windows 环境未安装 `make` 时，可在已配置 TeX Live 的终端中执行：

```sh
latexmk -xelatex -interaction=nonstopmode -halt-on-error -file-line-error -outdir=.build main.tex
```

此命令输出 `.build/main.pdf`，其正文与 Makefile 生成的 PDF 相同。也可在 TeX 编辑器中打开 `main.tex`，选择 XeLaTeX，并编译至目录及交叉引用稳定。

macOS 正文采用宋体 Regular / Bold，标题可使用黑体；其他系统在这些字体不存在时使用 TeX Live 提供的 Fandol 字体。不同字体可能改变换行与页数，需在对应环境重新检查排版。

清理 Makefile 产生的中间文件：

```sh
make -C "文档撰写/项目需求文档" clean
```

此操作保留本目录中已命名的最终 PDF、源码和验证记录。
