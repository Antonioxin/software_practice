# 目标用户
目标用户是成年人，而不是儿童本身，主要包括：

- 家长与成年消费者
- 礼品购买者
- 零售商、批发商、进口商及其采购人员
- 教育机构、活动机构的采购人员
- 已合作或潜在经销商

虽然产品服务儿童运动、协调能力和亲子互动，但网站明确规定：账户注册、交易与个人信息收集均面向成年人，不创建儿童账户，也不主动收集儿童个人信息。

# 用户操作
用户在网站上主要要完成四类事情：

- 浏览与查询：浏览产品、按年龄/玩法/场景筛选，搜索产品、文章、FAQ、下载资料，查找附近经销商。
- 购买与售后：消费者可收藏商品、加入购物车、结算购买（象征性，不需要实现真实的支付业务）、查看订单、申请退换货；若暂未开启零售交易，则转为“在哪里购买”或联系咨询。
- 商务合作：潜在经销商提交申请；已获批经销商查看专属目录、价格、库存与交期，批量下单、询价、下载私有资料，并管理企业资料和子账号。
- 获取支持与内容：阅读玩法指南、家庭活动和安全信息，下载说明书/证书，提交联系或售后表单，订阅邮件。
- 运营管理：平台员工在后台发布和维护商品、价格、订单、经销商、文章、Banner、FAQ、SEO 与数据报表。

可概括为：前台用户完成“了解—比较/咨询—购买或合作”，后台人员完成“维护—运营—分析”。

# 项目目标
项目核心不是简单复刻旧网站，而是把静态品牌站升级为可持续运营的动态业务门户。

要达成的目标包括：

- 展示品牌与产品：清晰传达 WEMOVE SPORTS 的运动游戏玩具定位、产品价值、玩法、安全与亲子使用场景。
- 促进转化：支持零售购买、产品咨询、查找经销商、经销商申请、批发询价和经销商下单。
- 建立统一运营后台：运营人员无需改代码，即可维护产品、图片、文章、Banner、下载资料、经销商信息和 SEO 内容。
- 支撑 B2C 与 B2B：既服务普通消费者，也服务零售商、批发商等经销商，并按角色隔离价格、订单和资料权限。
- 提升搜索流量与可衡量性：通过独立页面、SEO、结构化数据和行为埋点，提升自然搜索曝光，并分析浏览、询价、注册、加购和下单等转化链路。
- 保证长期可用：实现响应式适配、多语言、权限审计、安全保护和可扩展的数据结构。
