## 覆盖要点

- 既有标题、段落、嵌套列表与链接在区块解析／保存往返中保留。
- 图文块支持插图库和已上传媒体、替代文字、图注、配文、移动及移除。通栏图下的配文保留为后续正文。
- 前后端仅接受六张受控插图路径和规范媒体 UUID 地址；外站图片、数据 URL、路径绕过、任意样式、事件属性与 `srcset` 被过滤。
- 上传的正文图片在保存与发布时合并进入媒体引用，显式封面顺序优先，合计最多 20 张；引用保护及公开访问规则沿用文件模块。
- 正文图从后台独立配图池分离，删除后不会在图库中重新出现，独立封面仍保留。
- 修复了清洗前的自动 HTML 缩进导致重复保存／发布时空白变化的问题，清洗后的正文可稳定往返。
