## 可复现命令

从仓库根目录执行：

```bash
npm --prefix project-implementation/apps/web run test
npm --prefix project-implementation/apps/web run build
mvn -f project-implementation/apps/api/pom.xml verify
```

本机受限 Java 环境不能动态附加 Mockito agent，因此本次 Maven 命令增加了 `-DargLine=-javaagent:<本机 Maven 仓库中的 mockito-core-5.17.0.jar>`；同时使用 `-q -o`。这是测试运行参数，不是应用的启动依赖或业务配置。

真实 API 冒烟使用已启动的隔离实例，传入其管理员测试邮箱，并通过 `CONTENT_SMOKE_ADMIN_PASSWORD` 环境变量提供密码：

  --base-url http://127.0.0.1:8081/api/v1 \
  --admin-email content-admin@example.test \
  --allow-test-writes

## 关键回归结果

- 文章/FAQ 草稿、下线记录对游客直接读取返回 404；发布内容可读，首页只展示有效推荐。
- Banner 必须有有效图片与目标；成功启用后进入 `/home`，下线后立即消失。媒体在没有公开引用时对游客返回 404。
- 同幂等键重放不会重复创建或发布；旧 `expectedVersion` 更新返回 409，并保留前端编辑输入。
- 资料按 PUBLIC/DEALER/INTERNAL 过滤元数据和下载；经销资格通过后可下载，暂停合作后使用相同会话和旧链接无法下载。
- PDF 替换使旧 `downloadId` 失效。非法替换和审计失败都保持原版本与原文件可用；图片存在草稿/公开引用时禁止删除。
- 文件扩展名、声明 MIME 与实际内容不匹配时拒绝；真实 WebP 解码测试通过。标题等文本按 Unicode 码点计数，100 个 emoji 标题与 101 个越界标题分别验证。
- 服务端清洗危险 HTML；前端不使用不受控的 `v-html`。站内链接保留，脚本 URL 被拒绝或剥离。
- 品牌保存不再发送只读 `version` 字段；服务条款/隐私版本限长与身份同意记录一致。改版后注册策略读取新版本，旧版本注册被拒绝。
- 下线/下架/失效的首页推荐可在后台取消，不能新增未发布推荐。

## 本机运行状态

验证完成后，已对原配置数据库做一致性备份，再在原 `8080` 端口启动最终构建。原数据库成功追加 V10/V11，原 `5173` 前端可直接读取新内容。备份、运行 JAR 和详细测试日志保留在忽略的 `.local/` 目录，未提交账户凭据或本机配置。

本次修复还包含经销模块暂停合作的既有时间类型错误：Hibernate HQL 的 `CURRENT_TIMESTAMP` 不能赋给 `Instant` 字段，现改用同事务中的 `Instant` 参数。该修复通过经销申请/审核/暂停以及私有下载撤销流程验证。
