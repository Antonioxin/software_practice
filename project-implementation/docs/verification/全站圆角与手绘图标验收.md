# 全站圆角与手绘图标验收

日期：2026-09-08。本次只调整前端外观与装饰图标，不更改数据和业务操作。

## 统一规则

- 小标记 8px、输入与按钮 12px、卡片 20px、大面板 24px，集中定义在 `apps/web/src/theme.css`。
- 覆盖内容与文件、商品与库存、账户、交易、经销合作和客服模块；页面边缘和表格行之间的分隔线保留。
- 文本搜索使用现有 `search.webp`，输入文字左侧预留 44px。原本已有放大镜按钮的商品搜索沿用其入口。
- 27 种既有手绘素材均有对应用途，新增、删除、筛选、排序、返回、物流、历史等操作按语义配图。装饰图片为空替代文本，不改变按钮的可访问名称。
- FAQ 使用原生 `details`，收起显示加号，展开显示减号；显式保证隐藏规则高于图标组件的 scoped 样式。
- 提交咨询表单去除浏览器自带的直角 fieldset 外框，保留内部圆角选项卡。
