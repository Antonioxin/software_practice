# 运行与验证手册

## 1. 前置环境

- Node.js 20+ 与 npm。
- Java 21 与 Maven 3.9+。
- 下列命令及商品库存冒烟脚本使用 PowerShell。
- MySQL 8.x，数据库名建议为 `wemove`，应用账户只授予该库所需权限。

本模块没有独立应用进程，从 `project-implementation` 的整合应用启动。

## 2. 启动

PowerShell 示例。以下各个命令块均从仓库根目录开始执行；同一命令块内的相对切换按顺序执行：

```powershell
$env:DB_URL = 'jdbc:mysql://127.0.0.1:3306/wemove?useUnicode=true&characterEncoding=utf8&serverTimezone=UTC&allowPublicKeyRetrieval=true&useSSL=false'
$env:DB_USERNAME = 'wemove_app'
$env:DB_PASSWORD = '<local-password>'
$env:BOOTSTRAP_ADMIN_EMAIL = 'admin@example.test'
$env:BOOTSTRAP_ADMIN_PASSWORD = '<strong-local-password>'

Set-Location project-implementation/apps/api
mvn spring-boot:run
```

另开终端：

```powershell
Set-Location project-implementation/apps/web
npm ci
npm run dev
```

打开 `http://localhost:5173/products`。管理员登录后访问 `/admin/products` 和 `/admin/categories`。首次启动由 Flyway 自动执行 V1/V2；JPA 仅 `validate`，不会暗中改表。

## 3. 自动检查

```powershell
Set-Location project-implementation/apps/web
npm run typecheck
npm run test
npm run build

Set-Location ../api
mvn verify
```

后端已在 `http://127.0.0.1:8080` 运行时，执行 B 冒烟脚本：

```powershell
Set-Location project-implementation
./scripts/smoke/catalog-api.ps1 `
  -ApiBase 'http://127.0.0.1:8080/api/v1' `
  -AdminEmail 'admin@example.test' `
  -AdminPassword '<strong-local-password>'
```

脚本会对种子商品 `WM-BOWL-003` 增加 2 件库存，并产生一条写有“角色B接口冒烟补货”的流水；它应在专用测试库执行。

## 4. 手工验收清单

1. 在公开列表切换价格排序、年龄和场景，刷新后查询保留，返回详情后条件仍在。
2. 搜索不存在的名称，确认空状态可一键清除；停止后端确认出现可重试错误。
3. 检查有货、缺货、下架详情；公开页不应显示经销参考价。
4. 以管理员保存不完整草稿，直接发布应显示缺少字段；补全后发布，前台下次请求可见。
5. 修改已有 SKU、使用重复 SKU、停用被引用分类、减库存至负数，均应被服务端拒绝。
6. 在 360、768 和 1440 px 宽度检查列表、详情、编辑器和后台表格，再以键盘完成主要操作。

## 5. 常见问题

- V2 失败后不要直接改已在团队共享环境成功执行的迁移；开发期未发布时可重建专用库。
- 401 表示未登录，403 表示不是管理员，409 通常是版本、状态、唯一性或幂等冲突，422 为字段／查询校验。
- 开发时前端通过 Vite 代理访问 8080；如改后端端口，需同步修改 `vite.config.ts`。
