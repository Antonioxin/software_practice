## 协作里程碑建议

- 第 1 次集成：其他成员只依赖 OpenAPI 与 `IdentityPort`，不直接读取 A 的表。
- 第 2 次集成：角色 D 替换 `DealerIdentityPort`，角色 F 替换 `AuditPort`。
- 第 3 次集成：完成业务入口和返回路径，统一导航、错误码与权限能力名。
- 冻结前：全组执行端到端主路径、越权、重复提交、并发和移动端回归。

变更契约时，应先修改 `project-implementation/contracts/openapi/identity.yaml`、在讨论记录中写明兼容性结论，再修改实现。破坏性改动需全组确认并提升 API 版本。
