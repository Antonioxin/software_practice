# 静态界面与开发预览

本轮在共享 Vue 3 + TypeScript 应用上建立简约、手绘、整洁的初版界面，作为成员 E 后续开发及 A/B/C 现有页面联调的公共展示基础。范围包括身份账户的 5 条、商品库存的 6 条、零售交易的 6 条业务路由，以及首页和 404 页面。

这里“静态”指本版没有装饰动画、自动播放、三维场景或滚动特效。导航、菜单、筛选、表单、分页与弹窗仍是可以操作的 Vue 界面；默认模式继续调用真实 API。只读开发预览是另一种显式开启的数据来源，供没有后端环境时检查展示和状态，不构成真实业务验收。

## 视觉与组件约定

- 基础颜色采用浅灰白画布、暖白卡片和深炭灰文字，首页保留大面积留白，深绿承担主题语收尾和主要行动按钮的强调色。
- 手绘图标优先复用用户提供的[视觉组件](../../../前端设计视觉参考/视觉组件/)，通过 [SketchIcon.vue](../../../apps/web/src/components/SketchIcon.vue) 统一使用。图标配合文字说明，避免只凭图形或颜色判断操作含义。
- 毛玻璃底座由半透明背景、细边框、轻阴影及 `backdrop-filter` 构成，主要用于公共导航和面板。不支持背景模糊时使用更实的背景色，文字保持可读。
- 字体组合使用用户提供的三种字体：Barlow Condensed 用于英文品牌和标签，Caveat 用于首页两行手写主题语，悠哉（Yozai）用于全站中文标题、正文、导航和表单。悠哉采用 Regular / Medium 两个字重，按中文字形分块加载；未收录的字符仍回退系统字体。
- 公共页面、登录注册、个人中心和管理后台分别复用 `PublicShell`、`AuthShell`、`SiteShell`，并共享品牌、页脚、按钮、表单、状态提示和响应式规则。移动端导航可展开，键盘焦点保持可见。
- 首页的四个功能入口收进公共导航的“快捷入口”下拉面板，默认关闭；桌面和手机均可直接展开，保留手绘小图标，移除首页大色块和额外展示面板。
- 本轮不新增 Three.js 或动画依赖。悬停、选中、展开等状态即时变化，不依赖动效传达结果。

运行素材的完整映射、压缩数据和许可证见[资源说明](../../../apps/web/public/assets/README.md)。公共样式入口为 [theme.css](../../../apps/web/src/theme.css)，业务页面继续保留已有数据和操作逻辑。

## 启动默认真实 API 模式

命令统一从仓库根目录执行；已有依赖时不必重复安装。

```bash
npm --prefix project-implementation/apps/web ci
npm --prefix project-implementation/apps/web run dev
```

Vite 默认使用 5173 端口，以终端实际输出的地址为准。打开 [首页](http://localhost:5173/) 或 [商品列表](http://localhost:5173/products)。URL 没有 `preview=1` 时保持真实 API 模式，`/api` 默认代理到 `http://localhost:8080`；可通过 `VITE_API_PROXY_TARGET` 指定联调后端地址。

真实 API 模式需要启动后端并完成数据库配置，步骤见[身份账户运行手册](../identity/运行与验证手册.md)、[商品库存运行手册](../catalog/运行与验证手册.md)及[工程入口](../../../README.md)。本轮界面改版不替代数据库初始化和登录认证。

## 只读开发预览

只读预览仅在 Vite **开发环境**中，且地址显式包含 `?preview=1` 时启用。生产构建不根据这些参数启用样例身份或样例接口。最简单的入口是[首页预览](http://localhost:5173/?preview=1&role=guest&state=normal)。

| 参数 | 可选值 | 行为 |
| --- | --- | --- |
| `preview` | `1` | 显式开启开发预览；未设置时使用真实 API |
| `role` | `guest`、`user`、`admin` | 游客、普通用户、管理员样例身份 |
| `state` | `normal`、`empty`、`error` | 正常样例、业务空数据、业务读取错误 |

省略 `role` 时根据首次访问路径选身份：`/admin/*` 为管理员，`/account/*`、`/cart`、`/checkout` 为普通用户，其余为游客。省略 `state` 时使用 `normal`。显式选择身份后，页面仍按该身份的能力运行路由限制；例如以 `guest` 打开后台可能进入登录页。

预览工具条用于选择业务场景、身份和状态。场景切换使用完整 URL 重新加载，并匹配适合查看页面的样例身份；退出预览回到 `/products`、清除预览参数并恢复真实接口模式。同一页面会话中的 Vue 导航仍保持预览隔离，即使筛选会替换地址参数。复制链接或刷新前应保留 preview=1；需要稳定分享某个场景时使用下表入口。

### 数据与操作边界

- 正常样例覆盖列表、详情、账户状态、商品条目、购物车、订单和后台表单，以方便检查版式和分支展示；数量、价格、用户信息均是虚构样例。
- 业务写入统一拒绝，包括注册、登录、登出、保存资料、商品或分类变更、购物车变更、创建及更新订单等。预览中出现 `403 PREVIEW_READ_ONLY` 表示写入已经被拦截，不能据此判定真实后端失败。
- `POST /checkout-previews` 是只读试算的特例：预览返回本地样例以显示确认订单页面，不创建订单、不扣库存，也不调用真实接口。
- 未匹配的预览接口返回明确的 404；没有真实 API 回退。预览不会连接真实后端补齐缺失样例。
- 可以在本地表单输入、切换选择、展开菜单或查看弹窗，这些视图交互不表示修改已经保存。

因此本模式适合视觉核查、响应式检查、交互分支探索和跨成员界面讨论。会话与 CSRF、库存并发、订单状态流转、幂等处理、数据持久化等仍应使用真实 API 和测试数据库验收。不要把样例截图或“写入被拒绝”的结果记为业务测试通过。
