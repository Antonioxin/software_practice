# 文章图文排版

文章沿用商品详情页的六组玩法配图：实物器材保留材质和体积，人物使用简洁的卡通线条，底色与站点的暖白背景衔接。配图用于帮助理解玩法，具体使用条件仍以对应产品说明为准。

## 排版约定

| 内容形式 | 正文结构 | 适合内容 |
| --- | --- | --- |
| 左图右文 | `section[data-layout="image-left"]`，内含 `figure` 与文字 `div` | 配图解释一个步骤或一组要点 |
| 右图左文 | `section[data-layout="image-right"]`，内含 `figure` 与文字 `div` | 与上一段交替排列，形成阅读节奏 |
| 通栏图片 | 独立的 `figure` | 段落之间的场景图或文章结尾 |

`figure` 中包含图片 `img` 和可选图注 `figcaption`。图片替代文字 `alt` 描述画面内容，图注说明它与正文的关系。两者作用不同：图片未加载或使用屏幕阅读器时，替代文字仍能传达信息；图注则面向所有读者。

后台文章编辑器提供三种布局入口，选择商品玩法配图或媒体库图片后插入正文，再修改标题、段落和图注。手机窄屏以纵向排列呈现图文，避免把正文挤成窄列。文章原有的段落、标题、列表与链接仍可继续使用。

正文示例：

```html
<section data-layout="image-left">
  <figure>
    <img src="/assets/products/guides/balance-stones-guide.png"
         alt="卡通孩子在成人陪伴下走过彩色实物平衡石">
    <figcaption>从一条短短的路线开始。</figcaption>
  </figure>
  <div>
    <h3>今天，一起跨过小河</h3>
    <p>给每一站起个名字，轮流走过路线。</p>
  </div>
</section>
```

## 现有素材与示例

运行时素材位于 `apps/web/public/assets/products/guides/`，使用以下六个已有文件，不新增外部图片依赖：

- `balance-stones-guide.png`：亲子平衡石玩法。
- `rainbow-arch-guide.png`：彩虹拱搭建。
- `ring-toss-guide.png`：木质套圈。
- `team-board-guide.png`：多人协作板。
- `forest-kit-guide.png`：自然观察工具。
- `skip-rope-guide.png`：跳绳。

Flyway `V12__article_illustrated_layouts.sql` 为 V10 的三篇初始文章补充配图。它同时匹配文章 ID、类型、`version = 0` 与逐字节相同的原始正文，只有从未编辑的初始数据会更新。迁移仅修改正文、版本号和更新时间，保留标题、摘要、关联信息和发布状态；草稿仍为草稿，下线文章仍不公开。已经编辑过的文章可在后台自行添加图文块。

开发预览的两篇已发布文章也使用相同 HTML 结构，保留原有 ID、主题和关联媒体。预览数据独立于数据库，可从 `/articles?preview=1` 查看；它不代表真实内容已经保存或发布。
