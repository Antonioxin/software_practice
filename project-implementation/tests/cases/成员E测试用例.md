# 成员 E 测试用例（审核稿）

> **设计待用户审核；未执行。** 本篇 25 个用例仅规定准备、操作和判定方法，没有实际执行结果，所有证据均待执行后登记。优先级表示执行先后，不削减 P0 验收范围。

## 职责与依据

E 负责站点壳、导航、首页/品牌、文章/FAQ、媒体与下载文件，对应 FR-01、FR-02、FR-06、FR-07、FR-28、FR-29；另统筹响应式和可访问性。B 配合商品与引用，D 配合经销文件资格，A 配合身份、请求入口和部署，F 配合审计及证据汇总。独立复核按责任表逐场景分配，不能由实现者自行替代。

- [SRS V1.1](../../project-requirements/WEMOVE网站重构需求文档.md)：§3.1、§3.2.1、§3.2.6、§3.3—3.6、§5、附录 A。
- [团队分工与协作规范](../../project-requirements/WEMOVE团队分工与协作规范.md)：§2、§4、§7、§8。
- [需求责任与验收追踪表](../../project-requirements/WEMOVE需求责任与验收追踪表.md)：§2—7。
- [接口与数据协作契约 V1.0](../../project-requirements/WEMOVE接口与数据协作契约.md)：§2—8、§9.1、§11。

**当前局限：** [工程运行入口](../../README.md) 已说明 A/B 集成应用源码与启动方式；本轮未启动应用或执行测试，尚未核实 E/F 完整实现及全组验收环境就绪。本篇 API 名称、DTO、HTTP 细分和版本协议引用的是“待首次团队评审”的契约建议，不声称它们已获团队通过；用户审核后仍须与最终 OpenAPI 对齐。SRS 已明确的权限、大小、状态和屏宽不能因实现缺失而降为可选。

- 时间推进约定：除专门验证会话失效的用例外，推进测试时钟超过会话有效期后，以同一测试账号重新登录并取得当前 CSRF，再执行目标操作；同次业务重试保留原幂等键、原请求体和原业务版本，不把会话过期误判为去重失败。登录限次等测试使用其专用时钟与前置状态。

## 本篇数据与执行约定

- 成员 E 与测试账号无关：ADM 为管理员，U-A/U-B 为两个启用普通用户，D-A/D-B 为两个有效经销商，X 为停用账户；游客无会话。账号仅为别名，实际 ID 在执行记录中填写。
- 基线按 SRS §5.1：至少 18 商品/3 分类、3 文章/5 FAQ/2 Banner，2 公开 PDF/1 经销 PDF/1 内部 PDF。P-xx、ART-xx、FAQ-xx、BNR-xx、IMG-xx、F-xx 为本篇测试别名，材料标注“测试”。
- 所有用例独立初始化/清理；除步骤明确改变外，账户启用、商品库存及其他域业务记录保持初始值。文件测试使用独立存储目录，不操作正式资料。
- “脚本”为实现后应提供的可重复验证脚本；并发使用同步屏障同时发起，不能用先后点击代替。故障注入只在隔离环境。审阅只读数据可用于核对，不能手工改库伪造验收状态。
- 路径默认加 `/api/v1`；K 为 UUID 格式 `Idempotency-Key`，V 为当前 `expectedVersion`。幂等指同一次业务提交重试只有一次效果；版本冲突防止旧页面覆盖新数据。
- 每条证据执行后登记提交版本、环境、日期、执行/复核人、实际结果、状态、缺陷及脱敏证据地址；当前均为“未执行”。表内“成功/拒绝”均为预期而非已发生事实。
