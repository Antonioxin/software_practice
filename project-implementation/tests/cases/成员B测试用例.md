## 1. 职责、依据与执行约定

- 主责：FR-03 商品列表、FR-04 搜索筛选、FR-05 商品详情、FR-26 商品生命周期、FR-27 分类/价格/库存；横向负责商品投影、库存不变量、并发协作、数据字典与全组 ER 图汇总。
- 依据：[SRS V1.1](../../project-requirements/WEMOVE网站重构需求文档.md)、[团队分工 §2.1—2.3、§6—7](../../project-requirements/WEMOVE团队分工与协作规范.md)、[责任与验收追踪表](../../project-requirements/WEMOVE需求责任与验收追踪表.md)、[接口与数据协作契约](../../project-requirements/WEMOVE接口与数据协作契约.md)。简称“契约”指共同契约，其接口方案仍待团队评审；不能用实现偏差覆盖 SRS 行为。
- 运行参考：[B README](../../docs/modules/catalog/README.md)、[B 运行手册](../../docs/modules/catalog/运行与验证手册.md)、[B 验收追踪](../../docs/modules/catalog/角色B验收追踪.md)、[B OpenAPI](../../contracts/openapi/catalog.yaml)。B 已接入 `project-implementation` 共用应用，不另起一套登录/数据库。
- 回归来源：[既有成员 B 完成情况审核](../../docs/modules/catalog/成员B完成情况审核.md) R1—R10 及其中“C 接入前还需补齐的保证”。本文只引用缺陷描述设计回归，不复制旧验证结果，不修改该报告。
- 编号 T-B-01—26 为新增用例；优先级用高/中/低，表示风险而非需求 P0/P1。当前真实加购/订单需 C、经销专属入口需 D、媒体/文件需 E、中心审计需 F。模块服务测试可先开展，相关联合结果仍须真实消费者补验。
- HTTP 路径省略 `/api/v1`。正常写请求默认带允许 Origin、当前会话 CSRF；K 命令带 UUID 键，V 命令使用最新 `expectedVersion`。端口调用必须位于可信测试编排器/服务事务中，不新增公开扣库存后门。
- 每条用例从独立初态开始；通过业务接口及批准的初始化流程准备数据，不手工修改数据库伪造订单中间状态。读取数据库仅用于核对。故障注入、并发屏障与响应丢弃均使用隔离测试环境；并发用例必须同时起跑，连续点击不能证明并发。
- 库存核对式：\(S_{now}=S_{initial}+\sum adjustments+\sum cancellationReturns-\sum successfulPayments\geq0\)。付款减库存，取消只返还原扣减，加购、下单、询价不改变库存。金额按整数分：29.90 元为 2990 分，不能把小数分截为整数分后保存。

- 时间推进约定：除专门验证会话失效的用例外，推进测试时钟超过会话有效期后，以同一测试账号重新登录并取得当前 CSRF，再执行目标操作；同次业务重试保留原幂等键、原请求体和原业务版本，不把会话过期误判为去重失败。登录限次等测试使用其专用时钟与前置状态。

## 5. 提请审核与执行前待统一事项

1. **实际接口结构与共同契约存在分歧。** B YAML 为 OpenAPI 3.1.0、分页 `data` 加 `meta.totalItems`、后台默认 20、version 从 0 起；共同契约为 3.1.1、`data.items/page/pageSize/total`、默认 12、正整数 version。按共同契约设计 T-B-01/12，先由 A/B/消费者统一再执行结构断言；不得因此放宽 SRS 的每页上限 50、稳定排序和更新不丢失等要求。
2. 取消端口可以“拒绝调用方与原扣减不符的明细”或“完全以原扣减构造返还”；契约允许实现选择，但 **只能返还原数量且一次** 已明确。T-B-19 为这两种正确方式都设置客观判据，不把返还数量规则标为待定。
3. E 的真实图片/文件及引用、C 的购物车/订单事务、D 的目录/询价、F 的持久化审计需要集成环境。没有这些依赖时可记录 B 服务层结果，但 FR-05 与跨域库存/权限/回滚仍未完成联合验收。
4. 并发短等待预算、死锁最大重试次数由实现设计登记后用于超时判定；目前不虚构毫秒门槛。库存上限 SRS 仅明确非负整数，未给业务最大量，不自行引入任意上限；仍需说明存储/传输可表示范围并拒绝溢出，不允许绕回负数。
5. 请审核场景与覆盖是否符合分工。本文仅完成设计，没有运行业务测试、写入商品/库存，未将 R1—R10 标为修复或通过。
