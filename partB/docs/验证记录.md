## 发现并修复

首次真实 MySQL 迁移在 V2 初始库存流水处报 `Unknown column 'id'`。原因是 `inventory_balances` 的主键名为 `product_id`，种子 `SELECT` 误写为 `id`。改为 `product_id` 后删除临时测试库，从空 schema 重跑并通过。
