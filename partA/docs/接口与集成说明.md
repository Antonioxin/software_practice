# 接口与集成说明

## 协议约定

- 基础路径：`/api/v1`。
- 成功响应：`{"data": ..., "meta": ...}`，其中 `meta` 只在分页响应出现。
- 失败响应：`application/problem+json`，至少包含 `status`、`detail`、`code`、`requestId`。
- 时间：UTC ISO-8601；标识：UUID；分页从 1 开始，最大每页 50 条。
- 身份：Cookie `WEMOVE_SESSION`；浏览器请求必须使用 `credentials: include`。
- 写请求：先读取 `/auth/csrf`，发送 `X-CSRF-Token` 和白名单内 `Origin`。
- 管理命令：发送 UUID 格式的 `Idempotency-Key` 和最新 `expectedVersion`。

## 稳定能力名

| 能力 | 拥有者 | 用途 |
|---|---|---|
| `ACCOUNT_PROFILE_READ` | USER | 查看本人资料 |
| `ACCOUNT_PROFILE_WRITE` | USER | 修改本人资料 |
| `ADMIN_USERS_READ` | ADMIN | 用户列表与详情 |
| `ADMIN_USERS_WRITE` | ADMIN | 停用与恢复普通用户 |
| `DEALER_ACCESS` | 有效经销商派生身份 | 由角色 D 的适配器决定 |

前端能力只用于隐藏不可用入口；后端控制器和用例必须再次校验。

## 端口接入示例

角色 D 提供 Spring Bean 实现：

```java
@Primary
@Component
final class DealerIdentityAdapter implements DealerIdentityPort {
    public String derivedIdentity(UUID userId) {
        return cooperationRepository.hasEffectiveCooperation(userId) ? "DEALER" : "USER";
    }
}
```

角色 F 用同样方式提供 `@Primary AuditPort`。团队合并时应移除或用配置禁用默认适配器，确保相同端口只有一个首选 Bean。

## 错误处理建议

- `401`：清空本地身份状态并跳转登录；不要无限重试。
- `403`：保留用户输入并解释无权限或来源错误。
- `409 VERSION_CONFLICT`：刷新详情，让操作者基于新版本再次决定。
- `409 IDEMPOTENCY_CONFLICT`：生成新键前先核对原请求结果。
- `422`：按 `errors[].field` 映射到控件，同时保留顶部错误摘要。
- `429`：阻止自动重试并显示等待提示。

字段、例子和响应结构以 `contracts/openapi.yaml` 为唯一 HTTP 契约基线。
